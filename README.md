# dsh-playground

Playground repository for the dsh-superagent experience environment on US02.

- Agent account: @agent-clawsphere
- Open an issue starting with @agent-clawsphere to request work
- Accept mode starts in observe; review Decisions before switching to auto

## Usage

1. Open an issue that describes the change you want, one focused request per issue.
2. Mention `@agent-clawsphere` in the issue body or a comment.
3. Review the Decisions the agent reports; accept mode starts in observe, and you can switch it to auto once you trust the results.
4. The agent works on a ticket branch and opens a pull request, which you review and merge when it looks right.
